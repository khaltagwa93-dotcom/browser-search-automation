# نظام أتمتة البحث على الإنترنت من المتصفح

نظام مفتوح المصدر يستخدم **Playwright** للتحكم في متصفح حقيقي واستخراج نتائج البحث من DuckDuckGo / Google / Bing.

## المميزات
- واجهة عربية كاملة (RTL)
- دعم 3 محركات بحث
- تصدير النتائج إلى CSV
- سجل بحث محلي (localStorage)
- جاهز للنشر على Vercel

## التشغيل المحلي
```bash
npm install
npx playwright install chromium   # مرة واحدة فقط محلياً
npm run dev
```

## النشر على Vercel
يتم تلقائياً عبر الـ tools.

## ملاحظات هامة
- على الخطة المجانية لـ Vercel: timeout = 10 ثوانٍ → استخدم DuckDuckGo و limit=5~10
- على Pro: حتى 60 ثانية
- النظام لا يخزن أي بيانات على الخادم
